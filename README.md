# Ridemitra

Ridemitra is an Android application for ride sharing and transport services built using Kotlin and Jetpack Compose.

## Features
- User authentication and profile management
- Modern UI powered by Jetpack Compose & Material 3

## Getting Started
1. Clone this repository:
   ```bash
   git clone https://github.com/kesanapallibhavyasree/Ridemitra.git
   ```
2. Open the project in **Android Studio**.
3. Build and run on an Android device or emulator.
